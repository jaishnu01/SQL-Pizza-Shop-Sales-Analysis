# 🍕 Pizza Shop Sales Analysis – SQL Project

## 📌 Project Overview
This project focuses on analyzing pizza shop sales data using **MySQL**. It explores sales performance, customer behavior, pizza categories, and revenue through SQL queries.

## 🎯 Objectives
- Analyze total pizza sales and revenue.
- Identify popular pizzas and categories.
- Understand customer purchasing patterns.
- Practice SQL queries for business analysis.

## 🛠️ Tools & Technologies
- MySQL
- SQL

## 📂 Database Tables
- `categories`
- `customers`
- `pizzas`
- `orders`
- `orderdetails`

## 📊 SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions: SUM, AVG, COUNT
- LIKE
- INNER JOIN
- CROSS JOIN
- Subqueries

## 🔍 Key Insights
- Total pizzas sold: **46**
- Total estimated gross sales: **₹15,144**
- Average listed pizza price: **₹340**
- Top revenue-generating pizza: **Paneer Special**
- Highest-revenue category: **Non-Veg**

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open MySQL Workbench.
3. Create or select a database.
4. Import and execute the provided `.sql` file.
5. Run the queries to explore the sales data.

## 📚 Learning Outcome
Through this project, I gained practical experience in SQL querying, data analysis, table relationships, joins, aggregate functions, and extracting meaningful business insights.
